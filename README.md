# Data Structures & Algorithms

A structured repository documenting my continuous learning and algorithmic problem-solving practice. As a Cloud and Backend Engineer, I maintain this workspace to refine my algorithmic thinking, explore efficient data structures, and maintain hands-on fluency in Python and Go.

## 🗂 Repository Architecture

Solutions are categorized by algorithmic pattern rather than arbitrary difficulty. This reflects a modular approach to problem-solving, focusing on the underlying architectural concepts (e.g., Sliding Window, Two Pointers, Graph Traversal).

Files are 4-digit zero-padded by their standard problem indices (e.g., `0217_Contains_Duplicate.py`) to maintain a clean, sequential file system tree.

```text
.
├── 01_Arrays_and_Hashing/
│   ├── 0001_Two_Sum.py
│   ├── 0217_Contains_Duplicate.py
│   └── 0242_Valid_Anagram.py
├── 02_Two_Pointers/
│   └── 0125_Valid_Palindrome.py
└── README.md
```

## ⚙️ Engineering Standards

Every solution in this repository is treated with the same rigor as a production pull request. Each file includes:
- **Problem Context:** Direct link and constraint summaries.
- **Edge Cases:** Explicit documentation of boundary conditions handled.
- **Complexity Analysis:** Rigorous Big-O time and auxiliary space evaluation.
- **Clean Code:** Adherence to professional naming conventions and language-specific best practices (avoiding unnecessary memory overhead).
